wechat-triage-hud —— 使用说明
================================

1) 填 Key
   把同目录的 .env.example 改名为 .env，用记事本打开，填上你的 TypeSafe API Key
   （apikey_ 开头那一串）。没有 Key 面板也能打开，但不会出判断结论。

2) 启动
   双击 wechat-triage-hud.exe。面板会吸附在微信窗口旁边（微信需要先登录并显示在屏幕上）。

3) 第一次用
   · 面板会提示填「我在本群的昵称 / 职责 / 群性质」（私聊里是「我和这人的关系」）——
     这些判据决定"该不该回"这类结论准不准，只存在本机。
   · 数据、日志、设置都在同一个文件夹的 out\ 里（不是临时目录）：
       out\jev_audit.jsonl       每次调用一行（含原始请求/响应，最敏感，面板「日志」按钮可清）
       out\group_meta.json       你填的群昵称/职责/群性质/关系
       out\settings.json         频率、成本上限、阈值
       out\speaker_history.json  每人累积的历史消息

4) 面板怎么用
   · 左列点一个人 → 右栏出对他的判断；「风险」一行点一下可看具体概率
   · 右栏「他最近的消息」里点任意一条 → 单独判这一条，点「← 返回按人判断」回来
   · 标题栏：📌 固定位置 ·「关闭」收成小球（面板收起、球留在屏幕上，点球展开；外环颜色=状态）
   · 退出：右键面板 →「退出」；暂停采集：Ctrl+Alt+H 或托盘菜单
   · 设置（频率 / 每日成本上限 / 阈值 / Key）：右键面板 →「设置…」

5) 看不到判断？
   · 微信最小化、或被别的窗口挡住时，面板**故意不扫描**（截屏会读到别人的窗口），
     面板上会写明原因；把微信切到前台即可。
   · 面板默认沉默：没人需要你出手时它不显示任何结论，这是设计。

6) 排查问题
   建一个 run_debug.bat，内容两行：
       set JEV_HUD_DEBUG=1
       wechat-triage-hud.exe
   用这个启动，过程会写进 out\hud_debug.log。

注意：本工具只做判断，不注入微信、不替你回话；退出后不残留进程。
